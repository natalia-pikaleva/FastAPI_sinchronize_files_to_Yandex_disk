# Сервис по синхронизации файлов

## Применение

Приложение позволяет синхронизировать файлы локальной директории с директорией на Яндекс.диске

## Подготовка и запуск приложения

1. Клонируйте репозиторий в среду с docker
2. В корне репозитория создайте файл .env с вашими данными (в шаблоне .env.template прописано, какие должны быть
   данные).

- DIRECTORY_PATH должно быть вида /app/directory
- DEV_DIRECTORY_PATH - это путь к вашей локальной папке на компьютере, например, /app/data

3. Для сборки контейнера в корне репозитория пропишите команду docker compose up --build
4. После сборки контейнера приложение запускается командой docker compose up

## Использование приложения

- После запуска приложения перейдите в любой браузер и в строке адреса введите http://0.0.0.0:8000
- Нажмите на кнопку Запустить синхронизацию. Файлы будут синхронизированы, результаты вы увидите на странице в браузере
- При возникновении ошибок перейдите в консоль
